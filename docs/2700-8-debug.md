## What `0x2700, 8` is (Failure A)

Logged from `pouch/src/cert.c` (`authenticate_server_cert()`):

| Value | Meaning |
|-------|---------|
| `0x2700` | mbedTLS `MBEDTLS_ERR_X509_CERT_VERIFY_FAILED` |
| `8` | `MBEDTLS_X509_BADCERT_NOT_TRUSTED` — server chain does not terminate at the **CA compiled into firmware** |

The trust anchor is **`pouch/src/goliothrootx1.der`** (Golioth Root X1), baked in at **build time**.
The gateway sends the server cert chain at **runtime** over BLE GATT.

This is **not** a J-Link, OpenOCD, or readback-protection error. It is **firmware + TLS/crypto stack + build config**.
